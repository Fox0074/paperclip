# Paperclip + codex.sale: установка с нуля

Установщик собирает проверенную версию этого форка, запускает Paperclip и службу создания отдельных контейнеров для агентов. Настраивает подключение codex.sale для новой компании. Старые компании, задачи и контексты не импортируются. Агенты и платные задания автоматически не запускаются.

## Что нужно

- Ubuntu 24.04, доступ `sudo`, работающий systemd.
- Docker Engine с командой `docker compose`, Git, Python 3 и `ssh-keygen`.
- Доступ сервера к GitHub, GHCR и codex.sale; свободное место для Docker-сборки. Образ включает зависимости и собирается локально, поэтому первая установка занимает несколько минут.
- API-ключ codex.sale и цены выбранной модели **в долларах за миллион входных и выходных токенов**. Каталог `/models` не содержит цены: установщик не придумывает тарифы и не записывает нулевую стоимость.

Docker установите по [официальной инструкции для Ubuntu](https://docs.docker.com/engine/install/ubuntu/). Остальные зависимости: `sudo apt install git python3 openssh-client`. Проверьте `sudo docker info` и `sudo docker compose version`.

## Скачать и запустить

```bash
git clone --branch codex/codex-sale --single-branch https://github.com/Fox0074/paperclip.git
cd paperclip
sudo python3 deploy/codex-sale/install.py --host 192.168.1.108
```

Замените IP на адрес своего Ubuntu-сервера. После клонирования вся установка запускается последней командой. По умолчанию используются `/opt/paperclip`, порт `3100` и общий бюджет `$50/месяц`.

1. Введите API-ключ в скрытом приглашении терминала. Он сохраняется вне репозитория, в защищённом файле, и затем импортируется в зашифрованное хранилище компании.
2. Скрипт соберёт образы, запустит панель и покажет одноразовую ссылку владельца.
3. В браузере создайте аккаунт владельца и пустую компанию. Когда увидите **Connect a model**, вернитесь в терминал и нажмите Enter — ключ OpenAI на этом этапе не нужен.
4. Укажите тарифы модели. Скрипт сам найдёт единственную компанию, подключит codex.sale и проверит каталог моделей и доступность службы контейнеров без платной генерации.
5. Обновите панель. На **Connect a model** выберите **codex.sale**. Также доступно **Agents → New agent → OpenCode → Provider setup → codex.sale**.

Пароль аккаунта вводится только в Paperclip. Локальный адрес панели использует HTTP и предназначен для доверенной домашней сети.

## Без ожидания браузера

```bash
sudo python3 deploy/codex-sale/install.py --host 192.168.1.108 --no-wait
```

После создания аккаунта и компании:

```bash
sudo python3 deploy/codex-sale/install.py --host 192.168.1.108 --configure
```

`--configure` настраивает подключение без повторной сборки и перезапуска панели. При нескольких компаниях добавьте `--company UUID`. Его можно получить в настройках компании или через API владельца.

Для автоматического запуска можно передать `--key-file /secure/codex-sale.key` (файл содержит только ключ, находится вне Git и имеет права `0600`), `--input-rate ЧИСЛО`, `--output-rate ЧИСЛО` и `--budget-usd 50`. Значение ключа не передаётся в командной строке. Создание аккаунта владельца и компании в браузере всё равно требуется.

## Повторный запуск и существующие установки

Повторный запуск того же коммита с теми же параметрами сохраняет базу, секреты, SSH-ключ, настройки и уже установленный бюджет. Ранее заданные активные ключи не заменяются. Меняйте ключи и бюджет через Paperclip.

Установщик не удаляет данные и не присоединяет существующую установку, которую создавали другим способом. Если `/opt/paperclip` уже занят, он остановится. Для отдельной проверки используйте свободный порт и другое имя:

```bash
sudo python3 deploy/codex-sale/install.py --host 192.168.1.108 --root /opt/paperclip-test --port 13100
```

Служба, контейнер, сеть и каталоги этой установки будут отдельными. Сохраняйте `--root` и `--port` при повторном запуске и `--configure`.

После `git pull` с новым коммитом установщик откажется обновлять прежнюю установку автоматически. Сначала проверьте новую версию отдельно. Порядок обновления кода: [сопровождение форка](../../doc/fork-maintenance.md).

## Проверка и диагностика

```bash
curl http://192.168.1.108:3100/api/health
sudo docker logs --tail 100 paperclip
sudo systemctl status paperclip-provisioner
```

Для `/opt/paperclip-test` имя контейнера — `paperclip-test`, службы — `paperclip-test-provisioner`. Маркер установки: `/opt/paperclip/codex-sale-installation.json`. Не публикуйте `.env`, `integration/codex-sale.env`, `integration/runtime-key`, приглашение владельца или каталог `data`.

Скрипт настраивает модель `gpt-6.1-sol`. Добавление моделей описано в [настройке пресетов](../../doc/execution-presets.md). Бюджет и стоимость рассчитываются по указанным тарифам; это не сверка с фактическим счётом codex.sale. При удалении агента его контейнер пока удаляет оператор после проверки нужных файлов.

## Готовое задание для ИИ-помощника

> Установи Paperclip с codex.sale из https://github.com/Fox0074/paperclip, ветка codex/codex-sale. Сначала прочитай deploy/codex-sale/README.ru.md и AGENTS.md. Проверь Ubuntu, sudo, Docker Compose и свободный адрес/порт. Используй deploy/codex-sale/install.py; не переписывай установщик вручную и не удаляй существующие данные. Секрет получи через защищённый файл вне Git или скрытый ввод владельца, не проси ключ в чат. Запусти установку, дай владельцу ссылку регистрации и дождись создания аккаунта и компании. После этого выполни настройку компании с подтверждёнными тарифами. Проверь health, пресет и отдельный runtime без платной генерации. Не создавай агентов и бизнес-задачи без отдельного указания. Для повторного запуска сохраняй исходные host/root/port и коммит.
