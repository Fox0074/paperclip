# Команда AI-Hack из 12 агентов

Это настройка существующей компании Paperclip с codex.sale. Она не сбрасывает компанию, не создаёт новую базу и не запускает коммерческий продукт. Скрипт использует обычный авторизованный API владельца, штатные задачи, версии инструкций, окружения и бюджетные политики.

## Состав и первоначальные бюджеты

Общий месячный бюджет компании: **$50**. Лимиты ниже утверждены владельцем 14 октября 2026 как первоначальное распределение; сумма месячных лимитов — $50. Владельцу доступны изменения в Paperclip. Повтор настройки сохраняет изменённые владельцем промпты, модели и лимиты.

Все профили первоначально используют реально настроенную **codex_sale/gpt-6.1-sol**. Это один доступный в текущем preset вариант с известной существующей конфигурацией стоимости. Скрипт не придумывает цены других моделей и не меняет ключи, тарифы или соединения. Метка профиля описывает специализацию; она не означает отдельную модель.

Таймаут запуска: 900 секунд; максимум параллельных запусков агента: один; максимум автоматических recovery-повторов: два. Периодический heartbeat выключен на время проверки команды; назначения будят агента через wakeOnDemand. Пустая очередь не должна создавать платные холостые циклы. Для продолжения утверждённой цели используйте реальные задачи/передачи и штатный watchdog, а не отдельную автоматизацию очистки.

## Применение

Проверьте актуальную компанию и наличие preset codex-sale. Через штатный CLI-auth подключите установщик к аккаунту владельца; временный JSON с результатом challenge (включая boardApiToken) храните вне Git, root:root 0600. Подтверждение в браузере обязательно. Пароль и токен не нужны в чате.

```sh
sudo python3 deploy/team/configure.py \
  --base http://SERVER_IP:3100 \
  --company COMPANY_UUID \
  --auth-file /protected/path/team-auth-challenge.json
```

Скрипт сопоставляет роли по teamRole, имени AI-ROLE или ROLE. Несколько совпадений или terminated-роль останавливают настройку до изменений. Существующий COO сохраняет ID и историю. Первоначальная настройка помечается завершённой только после сохранения версии промпта и бюджетной политики. Повтор не восстанавливает шаблон поверх правок владельца.

После работы отзовите временный доступ через `/api/cli-auth/revoke-current` и удалите защищённый файл установщика.

## Управление

- Агент → Configuration: модель, окружение, иерархия, инструкции и параметры запуска.
- Агент → Instructions: индивидуальный AGENTS.md, версии и редактирование без изменения исходников.
- Агент → Budget: штатный месячный бюджет и расходы.
- Агент → Configuration → Advanced Run Policy: суточный лимит и лимит задачи (в центах USD), число recovery-повторов, таймаут.
- Компания → Budget: общий месячный бюджет; его изменения доступны владельцу.
- Issues и Runs: единственный ответственный, история передач, ошибки, фактические результаты, артефакты.

Агенты не могут повышать свои лимиты через общий PATCH агента. Они не имеют права создавать новые агенты или устанавливать skills; постановка разрешённых задач доступна. Изолированные контейнеры не получают Docker socket, управляющий SSH хомлаба, production-каталоги или платёжные учётные данные.

## Память

Личная память — `/paperclip/memory` в отдельном агентном home. Общая память компании — `/workspace/knowledge/company`; проектная — `/workspace/knowledge/projects/<project-id>`. Домашние каталоги других агентов не смонтированы. Общая память доступна команде; она не является хранилищем секретов. История, согласования, текущие задания и прикреплённые результаты сохраняются в Paperclip. Записи маркируются датой, источником и verified/hypothesis/outdated; инструкции требуют выбирать только релевантные сведения.

## Проверки и ограничения

```sh
sudo python3 deploy/team/validate.py --company COMPANY_UUID \
  --auth-file /protected/path/team-auth-challenge.json
```

Флаг `--start-scenario` создаёт одну изолированную тестовую задачу из integration_scenario.md. Цепочка CEO → CPO → Researcher → CPO → CTO → Developer → QA → COO → CEO выполняется реальными назначениями одной задачи. Отсутствие последнего маркера и успешного QA означает незавершённую проверку. Скрипт проверки конфигурации сам по себе не подтверждает выполнение цепочки.

Месячный бюджет использует штатный Paperclip hard stop. Суточный лимит (день Екатеринбурга) и лимит задачи запрещают новые запуски при достижении **учтённых** расходов. Это не предварительное резервирование всех токенов: текущий вызов может завершиться выше лимита, а расходы используют сохранённые оценочные тарифы, не счёт провайдера. Для гарантированного денежного потолка до каждого запроса нужен отдельный согласованный provider gateway или лимит со стороны провайдера. Скрипт не заявляет такую гарантию.

Изоляция технически исключает прямое управление production и платежи с отсутствующими учётными данными. Общий доступ контейнера в интернет не классифицирует каждую произвольную внешнюю операцию по риску. Для разрешения публичных публикаций или денежных интеграций потребуется отдельный исполнитель с программной проверкой конкретного согласования; пока они команде не выдаются.
